# 🗂️ Banco de Dores — Pesquisa do Paciente

> Insumo de pesquisa para os roteiros. Cada linha aqui pode virar **1 vídeo**.
> Origem das categorias: falas do WhatsApp ("Principais queixa dúvida dores do
> paciente", "Pergunta para responder os vídeos", "Contando história dor paciente").

## Como usar

1. Toda semana, **ouça os pacientes** (consulta, comentários, DM, WhatsApp).
2. Anote **queixas, dúvidas e perguntas** nas tabelas abaixo.
3. Escolha **1 item → 1 roteiro** usando o `MODELO-ROTEIRO.md`.
